A simple process,
with a little guidance.

You bring your story and materials. I’ll help turn them into a portfolio you can share.

  1. 01

    Choose Package

    Share your purpose, course/field and portfolio needs. I will suggest the most suitable package.

  2. 02

    Deposit & Content

    A 50% deposit is required before starting. Then you send resume, profile, skills, projects and links.

  3. 03

    GitHub Setup

    You create your GitHub account and add me as a collaborator. I will guide the setup step by step.

  4. 04

    Build & Publish

    I design, upload and publish your portfolio. After review and revision, final handover will be given.

How will my GitHub.io link work?

Your portfolio is published under your own GitHub account, using your username.

https://aisyahazmi.github.io

  1. 1. Create GitHub Account

    You create your own GitHub account using a professional username.

  2. 2. Create Repository

    Create a repository named exactly like your username.github.io.

  3. 3. Add Collaborator

    Add me as a collaborator so I can upload and set up your portfolio files.

  4. 4. Portfolio Goes Live

    Your online CV / portfolio will be published using your own GitHub.io link.

No password sharing is required. You only add me as a collaborator for portfolio setup.

A few good questions

Before we
get started.

New to online portfolios or GitHub? Here are the essentials.

Ask me on WhatsApp
Do I need a GitHub account?

Yes. You need your own GitHub account so the portfolio link can use your own username, such as yourusername.github.io.

Do I need to share my GitHub password?

No. You do not need to share your password. You only add me as a collaborator to help upload and set up the portfolio files.

Is there any monthly hosting fee?

No. The portfolio will be published using GitHub Pages, so there is no monthly hosting fee for this package.

Can I use the link in my resume or internship application?

Yes. You can add the GitHub.io link to your resume, LinkedIn profile, email signature, internship form or job application.

What do I need to prepare?

Please prepare your resume PDF, short profile, education details, skills list, project details, project screenshots if available, contact links and preferred design style.

Can I update my portfolio later?

Yes. Future updates can be requested as an add-on, such as adding new projects, updating resume files, changing profile details or adding new links.

Is this suitable for systems with login or database?

No. This package is for static online CV and portfolio websites only. It does not include login systems, databases, payment gateways or advanced web application functions.
